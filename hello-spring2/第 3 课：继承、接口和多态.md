# 第 3 课：继承、接口和多态

## 学习目标

理解继承、方法重写、抽象类、接口和多态。这些概念是 Spring 使用接口、实现类和依赖注入的基础。

## 继承与重写

```java
class Person {
    protected String name;

    public void introduce() {
        System.out.println("我是一个人");
    }
}

class Student extends Person {
    @Override
    public void introduce() {
        System.out.println("我是学生：" + name);
    }
}
```

`extends` 表示继承，`@Override` 表示子类重写父类方法。

## 接口

```java
interface Payable {
    void pay();
}

class Alipay implements Payable {
    @Override
    public void pay() {
        System.out.println("支付宝支付");
    }
}
```

接口只定义能力，具体实现由实现类完成。

## 多态

```java
Person person = new Student();
person.introduce();
```

变量类型可以是父类或接口，运行时执行实际对象的方法。Spring 的面向接口注入就是这种思想的应用。
