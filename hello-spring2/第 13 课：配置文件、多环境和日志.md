# 第 13 课：配置文件、多环境和日志

## 学习目标

使用 `application.yml`、Profile 和日志配置区分开发、测试、生产环境，为后续配置中心学习做准备。

## 基础配置

```yaml
spring:
  profiles:
    active: dev

server:
  port: 8080

app:
  name: hello-spring2
  welcome-message: 欢迎学习 Spring Boot
```

开发环境配置放在 `application-dev.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/hello_db
    username: root
    password: 你的密码
  jpa:
    hibernate:
      ddl-auto: update
```

Spring Boot 会合并基础配置和当前 Profile 配置。测试、生产环境只需要切换 `spring.profiles.active` 或启动参数。

## 日志

使用 `logging.level` 控制包的日志级别，开发环境可以打开 SQL 日志，生产环境应避免输出密码、JWT 和其他敏感数据。
