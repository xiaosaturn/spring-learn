# 第 21 课：创建第一个微服务系统

## 学习目标

把一个简单的单体调用拆成两个独立的 Spring Boot 服务，理解服务之间通过 HTTP 调用的基本方式。

```text
客户端
  ↓
order-service：8102
  ↓ HTTP
user-service：8101
```

## user-service

配置：

```yaml
spring:
  application:
    name: user-service
server:
  port: 8101
```

提供：

```text
GET /users/{id}
```

## order-service

配置：

```yaml
spring:
  application:
    name: order-service
server:
  port: 8102
```

使用 `RestClient` 调用用户服务：

```java
@Bean
RestClient userRestClient() {
    return RestClient.builder()
            .baseUrl("http://localhost:8101")
            .build();
}
```

```java
public UserResponse findById(Integer id) {
    return restClient.get()
            .uri("/users/{id}", id)
            .retrieve()
            .body(UserResponse.class);
}
```

## 测试

先启动 `user-service`，再启动 `order-service`，访问：

```text
GET http://localhost:8102/orders/100
```

## 当前方案的问题

用户服务地址写死在 `localhost:8101`，服务换端口或启动多个实例时需要修改代码，也没有服务发现、负载均衡和故障降级。后续课程会引入 Eureka、OpenFeign、熔断和网关。
